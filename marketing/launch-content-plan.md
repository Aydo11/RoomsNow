# RoomsNow organic marketing plan

## Positioning

RoomsNow helps people and housing professionals find current HMO, supported and specialist accommodation vacancies and contact the responsible provider.

## Priority search themes

1. **Ready to search:** HMO rooms to rent, HMO rooms near me, supported accommodation vacancies, supported accommodation Birmingham, rooms in shared houses.
2. **Learning before choosing:** what is an HMO, HMO room viewing checklist, how to find an HMO room, are bills included in HMO rent.
3. **Professional referrals:** supported accommodation referral, accommodation for care leavers, mental health supported accommodation, find a supported housing placement.
4. **Provider acquisition:** advertise HMO rooms, advertise supported accommodation, fill supported housing vacancies.

Use one clear search theme per page. Mention it naturally in the title, main heading, introduction, one subheading and useful internal links. Do not repeat a phrase simply to increase its count.

## Ready-to-post launch copy

### Facebook and Instagram

Viewing a room soon? Save this first. Our HMO room viewing checklist covers the bedroom, shared spaces, safety, bills and paperwork so you can compare rooms with more confidence. Read the checklist on RoomsNow, then search current accommodation.

### LinkedIn

RoomsNow has published a practical supported accommodation referral guide for social workers, support teams and housing professionals. It covers placement requirements, vacancy checks, proportionate information sharing and clear next steps. Read the guide and search current vacancies on RoomsNow.

### Google Business Profile

New on RoomsNow: straightforward guides for finding an HMO room, checking a property at a viewing and making a supported accommodation referral. Browse the guides and search available accommodation across the UK.

## Weekly routine

- Check Search Console for new queries, indexing problems and pages with impressions but low click-through.
- Check which cities and accommodation types have real live stock.
- Improve one existing page or publish one useful answer based on that evidence.
- Prepare one social post that links to the improved page.
- Record the change, target query and result so the next update builds on evidence.
